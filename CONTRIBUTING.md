# Contributing to Alter Ego Tools

Thank you for your interest in contributing to Alter Ego Tools! The following are some ways that you can contribute.

## Reporting Bugs

Please submit any bugs you encounter on our [GitHub issues](https://github.com/flufflesamy/alter-ego-tools/issues) page.
When submitting a bug report, please include details about your system (hardware, OS etc.) and also include steps
to reproduce the issue you are facing. Please also make sure you are running the latest version of Alter Ego Tools
before making a bug report.

## Pull Requests

If you wish to contribute code to Alter Ego Tools, please make a [pull request](https://github.com/flufflesamy/alter-ego-tools/pulls) on GitHub.
If you are contributing a large amount of code or a new feature, please discuss it first in the [issues page](https://github.com/flufflesamy/alter-ego-tools/issues)
before making a contribution.

## AI-Assisted Contributions

While Alter Ego Tools does not have a policy barring AI-assisted contributions, we believe that all AI-assisted code
must be understood and reviewed by the contributor. This means that you should be able to explain how your contributed
code works without the assistance of AI tools.

Any commits that includes substantial AI-assisted code (i.e. more than simple auto-completions) must be disclosed.
Please attach the following attribution to your commit message[^1]:

```
Assisted-by: AGENT_NAME:MODEL_VERSION [TOOL1] [TOOL2]
```

Commits MUST NOT be marked as co-authored by an AI tool. For instance, a commit that says `Co-authored-by: Claude`
will not be accepted.

Issues and pull requests that are entirely generated by AI tools will not be accepted and will be closed by
maintainers. This is to prevent low-quality content. Please author issues and PRs yourself.

## Pre-Commit Hooks

This project uses [prek](https://prek.j178.dev/) for pre-commit hooks. The hooks can be found in the repo's `prek.toml`
file.
The pre-commit hook includes useful tasks such as validating line endings, running REUSE lint, and cargo clippy and fmt.

To use them, [install prek](https://prek.j178.dev/installation/) and run `prek install` in the root of the repo.
Now whenever you make a git commit, the hooks will run automatically.

## Copyright Notices

When you contribute code, please attach a copyright notice on each file that you make or modify. Copyright notices
look something like this:

```rs
// SPDX-FileCopyrightText: 2026 Amy Poon <amy@amypoon.me>
// SPDX-FileCopyrightText: 2026 Jane Doe <jane.doe@example.com>
//
// SPDX-License-Identifier: GPL-3.0-or-later
```

Before making a pull request, please download the [reuse tool](https://reuse.readthedocs.io/en/stable/readme.html#install)
and run the `reuse lint` command (or use the pre-commit hook) to make sure there are no problems.

For more information on these notices, refer to [REUSE](https://reuse.software/faq/).

## Getting Help

If you need any help in contributing to Alter Ego Tools, please make an issue on the [issue tracker](https://github.com/flufflesamy/alter-ego-tools/issues).

[^1]: This is taken from the [Linux Kernel's](https://docs.kernel.org/process/coding-assistants.html#attribution) AI
contribution policy. Please refer to them for more examples.
