# Contributing to Alter Ego Tools

Thank you for your interest in contributing to Alter Ego Tools! The following are some ways that you can contribute.

## Reporting Bugs

Please submit any bugs you encounter on our [GitHub issues](https://github.com/flufflesamy/alter-ego-tools/issues) page.
When submitting a bug report, please include details about your system (hardware, OS etc.) and also include steps
to reproduce the issue you are facing. Please also make sure you are running the latest version of Alter Ego Tools
before making a bug report.

## Pull Requests

If you wish to contribute code to Alter Ego Tools, please make a [pull request](https://github.com/flufflesamy/alter-ego-tools/pulls) on GitHub.
If you are contributing a large amount of code or a new feature, please discuss it first in the [issues page](https://github.com/flufflesamy/alter-ego-tools/issues)
before making a contribution.

## Copyright Notices

When you contribute code, please attach a copyright notice on each file that you make or modify. Copyright notices
look something like this:

```rs
// SPDX-FileCopyrightText: 2026 Amy Poon <amy@amypoon.me>
// SPDX-FileCopyrightText: 2026 Jane Doe <jane.doe@example.com>
//
// SPDX-License-Identifier: GPL-3.0-or-later
```

Before making a pull request, please download the [reuse tool](https://reuse.readthedocs.io/en/stable/readme.html#install)
and run the `reuse lint` command to make sure there are no problems.

For more information on these notices, refer to [REUSE](https://reuse.software/faq/).

## Getting Help

If you need any help in contributing to Alter Ego Tools, please make an issue on the [issue tracker](https://github.com/flufflesamy/alter-ego-tools/issues).
